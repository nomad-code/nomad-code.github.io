Apple Watch app — slice 1

Greenfield watchOS companion for Yotta (bare Expo SDK 55). First running slice: a SwiftUI screen that builds and launches on the watch simulator — added the zero-tech-debt way so it survives every native regen.

✓ merged to master · 319ff97 ensure green · 62 tests Xcode 26.6 · watchOS 26.5 SDK Linear YOTTA-121

What shipped

  • ✓Watch target in targets/watch/ — SwiftUI YottaWatchApp + ContentView, bundle id com.yottaworkout.app.watchkitapp.
  • ✓Config-plugin approach via @bacons/apple-targets — target is regenerated on prebuild as a synchronized folder, so prebuild --clean can't wipe it. No hand-added Xcode target to lose.
  • ✓Companion wiring auto-generated: WKCompanionApp pairing + “Embed Watch Content” phase into the Yotta iOS app.

Prebuild papercuts fixed (config-driven)

  • ✓Firebase static link — plugins/withModularHeaders.js injects use_modular_headers! on prebuild. Replaces a manual Podfile edit that was silently lost on every --clean.
  • ✓pod install locale — CocoaPods 1.16 crashes on ASCII-8BIT normalization; run with LANG/LC_ALL=en_US.UTF-8. Documented in CLAUDE.md.
  • ✓Watch-sim destination gap — SDK 26.5 has no matching sim runtime (max 26.4), so scheme+destination builds are rejected. Work around with a direct -target watch -sdk watchsimulator build.

Build / run loop

# build + install + launch on the watch simulator npm run run-watch # build-only gate for the watch target npm run ensure:native:watch # JS gate — lint + tsc + 62 tests + bundle-check npm run ensure → green
