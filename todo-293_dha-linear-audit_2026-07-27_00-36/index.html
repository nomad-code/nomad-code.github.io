gh-project · the real fragility

This is ghp — the entire public tier of the tiered task model. AGENT.md routes every team-visible lookup through it (ghp issue portal-v2-iNN, board #26). Interesting wrinkle: bun 1.3.8 does exist via mise inside portal-v2 — which is how this session ran the test suite. It just isn't on the global PATH where ghp needs it.

Private tier is durable: Linear plus a pushed git repo. Public tier is one disk failure from gone. That asymmetry is the biggest thing this audit found.
