Three phones, a Spica 3, and a brother with a TrackMan — what plays where

Session theory: which launch monitors drive which sim software, whether phones can be launch monitors at all, and what the truly portable "range shots become real shots" rig looks like. Compatibility

Who talks to whom

The Spica 3 is not GSPro-only — but TrackMan and GOLFZON are closed at the software end, so the openness only runs one way.

HardwareGSProE6 ConnectTrackMan Virtual GolfGOLFZON software
GolfJoy Spica 3 (the one you hit on — not yours) native native adapter closed — TM hardware only closed — GZ bays only
TrackMan 4 (brother's) unofficial hacks only no native no
Phone camera apps (Golfboy / ShotVision / GolfTrak) via Open Connect API some (GolfTrak) no no

Consequence: the ecosystems meet at the vault, not at the sim. TrackMan sessions export the same CSV grammar as the 4.7G already in Timeline; Spica/GSPro shots already land in ~/ark/golf/ via SwingNerds. A session at your brother's joins as a CSV ingest, never as a live connection.

Accuracy honesty

The measurement tier list

TrackMan 4Radar + camera; measured spin; the reference standard.
Spica 327 data points, real reads; a tier below radar but trustworthy for practice evidence.
Phone appsBall speed + launch decent; spin is modeled, not measured. Tripod + ultra-wide lens required for long shots.

So the three phones' best role isn't launch monitor — it's the current rig: face-on + down-the-line video synced to the Spica's numbers. Phone-as-monitor is the forgot-the-Spica fallback, not the upgrade path.

Play anywhere

Three portable rigs

Rigs A and B assume buying or borrowing a Spica-class unit (~consumer photometric tier) — the Spica 3 in golf-spica isn't Brendan's.

A · The known-good rig net/mat → Spica 3 → Windows laptop → GSPro → SwingNerds → strokes gained

Real simulated rounds anywhere. Friction: GSPro is Windows-only, so a gaming laptop rides in the bag.

B · The no-laptop dream (verify first) net/mat → Spica 3 → E6 Connect on iPad

E6 runs on iOS; GolfJoy's adapter docs describe a PC path. If the iOS route works, the rig collapses to Spica + iPad + net.

C · The premium freebie brother's TrackMan bay → TrackMan Virtual Golf / Range

Superimposed range-shots-as-real-shots is TrackMan's built-in experience. Export CSVs afterward for the vault.
