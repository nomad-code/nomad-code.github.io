The segfault autopsy — why "needs GUI" was wrong

TODO-180 blamed "python op nested in python op". The crash backtrace says otherwise: _PyEval_MakeFrameVector dying at operator entry under rna_operator_exec_cb. The S2 spike's own tag_redraw shim had monkeypatched execute on a registered operator class — leaving RNA's cached callback dangling. The op was never safe to call after that; the GUI "worked" only because a human never ran the shimmed op.

# the fix is to not call the operator at all # its execute() is 4 lines around a pure-bmesh class: remesher = RM.BoundaryAlignedRemesher(ob) # no context bm = remesher.remesh(edge_length, iterations, quads=True) bm.to_mesh(ob.data) # no tag_redraw, no shim # plus two structural guards: # · stage split: convertmats ends with save+reopen — own process # · face budget: edge = max(spec, sqrt(area / 300k)) — DeepRough # at 86 ha can't kill the run (1.69 m vs spec 0.9 m, logged)
