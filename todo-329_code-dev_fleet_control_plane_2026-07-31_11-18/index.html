Equivalent by contract, not by copy.

M3 and M5 no longer need identical disks or matching Codex databases. They need the same ability to resolve a world, hydrate its source, claim one task, checkpoint it, and recover it without guessing.

02

Four contracts, four recovery owners

SOURCE

World manifest

Path, remote, branch, world and core · warm · on-demand profile. Git recovers it.

LOOP

Task packet

Issue URL, repo ref, decision, next action and checksum. Linear journals it.

OWNERSHIP

Fenced lease

One host/run, one epoch. Private Git compare-and-swap prevents double ownership.

HOME

Recovery class

Blueprint, durable, credential or runtime. Nothing gets “solved” by moving all state into ~/dev.
