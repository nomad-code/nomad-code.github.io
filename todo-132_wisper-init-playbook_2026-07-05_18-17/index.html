01the stack

Primary · superwhisper

Lifetime license, Parakeet TDT v3 local (≈2–6% WER, ~10× faster on the Neural Engine; large-v3-turbo as noisy fallback). Custom Modes = per-context STT + AI reformat + few-shot examples. URL scheme is the pedal hook: superwhisper://record, superwhisper://mode?key=….

Complement · Claude Code /voice

Native PTT (hold Space / meta+k rebind), coding-tuned, auto-injects repo + branch as hints. Cloud-only — good-internet convenience layer, never the Medewi primary. Hedge: VoiceInk ($40, GPL-3, local whisper.cpp/Parakeet).

Skip · Wispr Flow, Aqua, Talon

Wispr Flow + Aqua Voice: best UX, cloud-only at every tier — disqualified by Bali internet. Talon: command grammar for hands-free coding, not long-form prompt prose. And don't rebuild whisperx — transcribe-local stays batch.

02three modes, built day 1

prompt

Spoken ramble → precise agent instruction. Identifiers verbatim (paths, TODO-NNN), requirements bulleted, no preamble. Few-shot from your own archived prompts.

journal

First person, keep the voice, fix grammar only. For Linear journal comments and dna/ notes.

commit

Conventional format, ≤72-char imperative subject. Target: 100% of commit messages voiced by day 4.

Vocabulary before model size: seed 30–50 proper nouns (bpo, Medewi, KITAS, pedald, tmux, Qdrant, grove, Hyrox…) + 10 replacement rules. Kept in git at projects/wisper/vocab.md.

04the medewi block · jul 11–25
days 1–2Rig, not skill. Install, build 3 modes with real few-shot examples, seed vocab, pedal switch 1 end-to-end into a terminal = day-1 done-when. Drill: read existing prose aloud 10 min.
days 3–4Verbatim tier. Voice everything you'd type verbatim: Linear comments, commits. Drill: same 60-word paragraph 10×, watch corrections drop.
days 5–7Prompt tier. Every Claude prompt under 3 sentences must be voiced. Re-speak yesterday's typed prompts, diff quality. The quit-zone — fix is lower stakes (journal dumps), not pushing harder.
days 8–10Long-form tier. All prompts voiced unless heavy literal code. The elite loop: speak whole thought → ≤10s keyboard touch-up → pedal-3 send. Edit by keyboard, never by voice.
days 11–12Offline stress test. Kill wifi half a day: local Parakeet only, no /voice, no cloud reformat. Tune vocab from the error log.
days 13–14Consolidate + measure. ≥120 effective WPM · <20% corrections · ≥80% prompts voiced · PTT unconscious. Distill conventions into dna/ — the skill survives in git, not muscle memory.

Off-season Jul 25 → Dec: keyboard PTT keeps voice the default channel; % voiced below ~50% triggers a 3-day refresher. Dec 2026 / Jan 2027 re-entry: pedals return → pedald v1 (the ~200-line mido router), profiles.toml as truth. Realistic ceiling: 2 weeks buys fluency-with-touch-ups (~2× prompt throughput); 130–150 WPM at 95% accuracy is a ~6-month asymptote.
