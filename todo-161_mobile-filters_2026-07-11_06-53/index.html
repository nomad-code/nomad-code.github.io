Live — the shipped component's contract

Same semantics as apps/portal/app/components/maps/map-filter-chips.tsx: native buttons, aria-pressed, category-color fill while active. Toggling filters the dot field the way markers unmount on the real map.

Geometry, guarded

In map view the page column owns 100dvh − header and the map flexes into whatever the chips leave — so adding a row above the map cannot re-introduce a scroll run-out under greedy gestures.

The mobile e2e viewport invariant was rewritten with the feature: it now asserts header → chips → map → bottom edge, each seam within 8px. Asserting the map at the header's edge would have hidden exactly the regression class it exists to catch.

Desktop — the control group

Nothing moved above md. The legend keeps the bottom-left overlay; the chip row is display:none. Both are the same state — chips and legend call the same toggleCategory.

A desktop e2e ride-along pins the split: legend visible, chips hidden.
