▸How to fill this deck — run the scraper
The scrape can't run from the bpo web session. The org egress policy blocks bunpro.jp + the CloudFront audio host, and the audio is copyright-gated so it never ships to the public mirror. This page is a local-file player: it reads your out/ folder in-browser, nothing uploads.
# in projects/bunpro-listening — one-time
npm i playwright && npx playwright install chromium
node scrape.mjs --login          # log in, press ENTER

# walk + export
node scrape.mjs --levels n5,n4,n3,n2,n1   # all levels
node scrape.mjs --sections L               # listening only
node scrape.mjs --dry-run                  # preview the URL walk
node export.mjs                            # anki.tsv + clips.json + media
Drop the out/ folder here or click to choose it — reads manifest.json / clips.json + the mp3s
