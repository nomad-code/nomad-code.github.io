Audit findings

The model is sound. These are the boundaries that prevent it from turning into a generic integration layer with BPO semantics leaking everywhere.

P0
World is absent from ResourceRef

Make BPO / Found / Dhamma mandatory before provider and account. This is a privacy boundary, not metadata.

P1
Semantic route mixes orthogonal axes

code-m5 is a useful alias, but must resolve to area=code, host=m5, role=worker rather than become canonical truth.

P1
Gateway is too broad

Keep policy, provider selection, identity mapping and sync in the control plane; push auth, retries, pagination and rate limits into adapters.

P1
Runtime and artifacts are missing capabilities

Deploy needs an execution boundary. Artifacts require projection provenance beyond a generic object-store write.

P2
One parent is not a knowledge graph

Use typed multi-edges for context, runtime, evidence and policy. Git supplies history; metadata supplies graph meaning.

P2
Provider parity is imaginary

Expose capability negotiation and explicit unsupported behavior; Linear initiatives and GitHub milestones are not interchangeable.

Correct the common reference

Resource identity is provider-native and world-fenced. Capability is how a caller reaches the resource—not part of the resource’s identity. Execution is a separate reference.

type ResourceRef = {
  world: "bpo" | "found" | "dhamma";
  provider: string;
  account: string;
  workspace?: string;
  kind: string;
  nativeId: string;
  url?: string;
  revision?: string;
};

type ExecutionRef = {
  host: string;
  taskId?: string;
  taskUrl?: string;
  lane?: string;
};

Resolution laws

1

Resolve world before using any credential, provider, or task adapter.

2

Resolve the longest known semantic prefix; return the remaining suffix as intent.

3

Keep the Codex task ID as runtime identity even when the title carries a perfect slug.

4

Publish artifacts as timestamped projections linked to Git revision and Linear issue.

The prompt title is an address into the knowledge graph—not the graph, not the workflow, and not the running task.

Deterministic routing precedes fuzzy retrieval. Git owns durable meaning. Linear owns the loop. Codex owns execution. The artifact makes the joined state legible.
