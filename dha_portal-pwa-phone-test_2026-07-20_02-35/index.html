Install it

iPhone · Safari

  1. Open the V2 test host using the button above.
  2. Tap Share, then Add to Home Screen.
  3. On iOS 26, leave Open as Web App enabled.
  4. Keep the name Dhamma.org and tap Add.

Android · Chrome

  1. Open the V2 test host using the button above.
  2. Open the three-dot browser menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm Dhamma.org, then launch from the new icon.

Pass checklist

  1. Icon: the home-screen icon is the gold Dhamma wheel, not a screenshot or letter tile.
  2. Standalone: launching it opens an app-like window without the normal browser address bar.
  3. Identity: the installed name is Dhamma.org and the status bar uses the dark-blue theme.
  4. Navigation: Home, course search, locations, and a schedule page all remain inside the app window.
  5. V2 persistence: fully close the app, reopen it from the icon, and confirm it still shows Portal V2 rather than Rails.
  6. Online contract: reload while connected. Offline behavior is deliberately out of scope for this first release.
