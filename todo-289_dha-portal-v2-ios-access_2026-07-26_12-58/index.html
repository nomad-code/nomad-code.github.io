The fork that wasn't

Blocked, mid-build. gh repo fork returned 403 — the repository exists, but forking is disabled. gh api repos/dhammaorg/portal-v2 confirms allow_forking: false, and flipping it needs admin. Brendan has maintain. No amount of retrying fixes that.

Which surfaced the better question: what was the fork actually buying? Brendan already has push upstream, so PRs were always same-repo. The fork bought exactly one thing — a repo the iOS app can see. A plain private repo buys that too, for zero org-admin action.

The decision

nomad-code/portal-v2 — a private mirror, seeded from upstream main. It sits inside the existing installation, so iOS reaches it natively. Upstream stays source of truth; the team's workflow doesn't change.

RuleWhy it's load-bearing
main is a mirrorRead-only copy of upstream main. Nothing local ever lands on it, so it can be force-pushed without thought. Drift dies at the root.
ops is the default branchScheduled workflows only run from the default branch — and the sync job force-pushes main. A workflow living on main deletes itself on its first run. ops holds workflows and nothing else.
Work on branchesCheap, disposable, and the mirror stays pristine.
Rebase before publishingThe 07-20 handoff recorded a branch 94 commits behind. Now enforced in code: publish-upstream refuses a branch that isn't a descendant of upstream base.
The upstream hop is dispatchedNever automatic. Brendan's identity on team-visible acts, and it is the tier boundary.

Two workflows, on ops

Down

sync-upstream

Hourly at :17, dodging the top-of-hour stampede. Force-pushes upstream main onto mirror main. No-ops when the SHAs already match.

Up

publish-upstream

Dispatch only. Branch in → rebase check → push to dhammaorg/portal-v2 → PR opened there. Refuses main. Re-running on an open PR just updates the branch.

Auth

UPSTREAM_TOKEN

One fine-grained PAT — owner dhammaorg, repo portal-v2 only, Contents and Pull requests both read+write. The default workflow token can't see a private upstream. Token lives in the remote URL, never echoed.

The gap a fork would've closed

No relation

GitHub doesn't know these two repos are related: no "N commits behind" banner, no cross-repo compare. The Action is the only link. That's the real cost of mirror-over-fork.
