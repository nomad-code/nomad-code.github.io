Three data planes, one local spine

Green flow is automatic local ingestion. Orange flow is permission-gated task context. The ledger has no automatic edge into ChatGPT—sharing remains an explicit decision.

Plane 01 · sources

Each Chromium profile owns its own History database. Chrome and the built-in browser do not merge automatically.

Plane 02 · archive

A safe temporary snapshot feeds the owner-only ledger. Watermarks make stale or empty sources obvious.

Plane 03 · context

ChatGPT may use relevant history only after a request and confirmation. That is task context, not durable coverage.

“History” is four different things

The important distinction is ownership: a browser database, an OpenAI conversation, a task's temporary context, and this new private archive have different retention and access rules.

LOCAL · COMPLETE FOR PROFILE

Chrome history

Chrome's SQLite database is the active source on this Mac. Synced-device activity may appear when Chrome sync writes it into the local profile.

  • visits + titles + raw URLs
  • recognized search terms
  • not automatically copied wholesale to OpenAI
LOCAL · SEPARATE PROFILE

ChatGPT built-in browser

Official guidance says it keeps its own profile and history. The two current candidate databases on this Mac are present but empty.

  • managed in Settings → Browser
  • does not inherit regular Chrome history
  • ChatGPT can request a relevant-history search
OPENAI · CONVERSATION DATA

ChatGPT chats and searches

Searches performed inside a chat belong to conversation data. The desktop app has a small local cache, but that cache is not a reliable complete export.

  • governed by ChatGPT data controls
  • not the same as Chromium History
  • use account export for authoritative coverage
REQUEST-SCOPED · NOT AN ARCHIVE

Chrome extension context

When you approve history access, relevant entries can enter the task context. OpenAI says it does not keep a second complete record of all Chrome actions.

  • no always-allow setting for history
  • page text, screenshots, and tool calls may enter chats
  • do not treat the extension as a backup

The tracking spine is small

Python's standard library does the whole job: discover profiles, copy a consistent-enough local snapshot, ingest idempotently, report only metadata, and let launchd repeat it.

def safe_snapshot(source, destination):
    target = destination / "History"
    shutil.copy2(source, target)
    for suffix in ("-journal", "-wal", "-shm"):
        sidecar = source.with_name(source.name + suffix)
        if sidecar.exists() and sidecar.stat().st_size:
            shutil.copy2(sidecar, destination / ("History" + suffix))
    return target
