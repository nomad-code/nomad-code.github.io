Three repos, one spine —
sync where it helps, lines where it matters

An audit of a three-repo context-layer family that shares a design system, a password wall, and a set of scripts down a one-way chain. The old sync was lossy (most shared files drifted unseen) and destructive (a run could overwrite local work). This pass makes the shared core single-source and safe to apply, turns silent drift loud, and writes the privacy boundaries down — without touching the upstream company repo.

good ways to sync

Four tiers replace track / watch

TierMeaningSync behaviorMembers
COREsingle-source, byte-identical auto-copied per-file, no --delete the 5 identical grove files (reset · tokens · viz · motion · components.js)
REPORTshould converge; drift is a risk never auto-copied; loud + non-zero exit grove/components.css, the shared sync engine
FORKper-world by design never copied; one quiet line on drift the gate identity, task & provenance scripts, per-world config
LOCALdownstream-only additions never synced, never reported grove/local.css — the home for any local override

Two moves make it safe: drop --delete and copy per file (new upstream files get added, local ones never clobbered); and keep components.css in REPORT — the one file with a history of legitimate local additions is reviewed, never auto-overwritten. A content invariant also guarantees the prompt-log script keeps its secret redactor, so that class of leak can never go silent again.

lines drawn

Where sync stops

Content privacy gradient

The company repo never receives personal or private-world content. Personal directories never ship to the public mirror — a positive allowlist plus a fail-closed tripwire enforce it. Private planning graduates to a public tracker only by an explicit, human-run step.

Per-world identity is a fork

The password gate's key, label, and theme, plus each world's task / provenance config, diverge on purpose. The sync reports them quietly and never copies them across worlds.

One-way direction

Mechanisms move downhill only. The lone upward move is a finished, re-gated artifact — no script, config, or content ever flows back up the chain.
