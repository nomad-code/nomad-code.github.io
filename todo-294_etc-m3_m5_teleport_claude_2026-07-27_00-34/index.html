What is true today

M3

  • Two live tmux sessions and three long-running Claude processes were observed.
  • The Claude executable those processes started from is now missing, so a restart is unsafe until installation is repaired.
  • Several repositories carry active dirty work and must not be swept into a bulk sync.

M5

  • Tailscale/SSH, Codex 0.145.0, the managed app-server, and Claude Code 2.1.212 are reachable.
  • No tmux or Claude worker session is currently running there.
  • Its BPO and etc clones contain local state, so handoffs need isolated worktrees.
The old bridge is only a stub. .zshrc calls ~/.config/claude/cc-handoff.py, but that file is absent on both Macs and was never committed. It also assumes identical absolute home paths, which M3 and M5 do not share.
