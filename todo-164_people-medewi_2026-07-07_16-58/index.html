How to make a person-ontology and grow it.

You asked "idk how to make a person ontology with the Apple ecosystem and scale it." You already are — this is just the shape of it, written down.

📝 Apple Notes / Contacts / IG / WhatsApp / 📸 → one per-person note · 👫🇨🇨 → place-cohort index · groups/medewi

The atom is one note per person, tagged 👫 + a country flag, named <name>-<venue>-<id>.md. The venue lives in the name and body. One memory hook + one backstory line is enough — SRS compression: as time compounds, the file gets smaller, not bigger.

---

Then add a bullet to dna/people/groups/medewi.md under the venue — the place-cohort index this page is built from. That's the layer you were missing: per-person notes answer "tell me about X"; the cohort index answers "who's at place." Both now exist in the repo.

The lesson TODO-164 taught the vault: you captured people by place-of-work, so "who works at Holy Tree" is a clean lookup — but "who goes to Pangea trivia on Thursdays" isn't, because nobody's tagged by the event they show up to.
