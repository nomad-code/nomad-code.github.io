Recovery lane explorer

M5 becomes primary

Lose M3

Continue from the durable runner without trying to copy M3's app database.

  1. Open the Linear issue from i17pm.
  2. Start or continue the matching M5 task at the same Git root/subdirectory.
  3. Hydrate from Linear journal plus Git branch/commit; use native handoff when the task supports it.
  4. Recover anything unpushed from the declared rescue capsule—not from live filesystem sync.
Invariant: no task may depend on a sleeping laptop's private database or unpushed worktree.
