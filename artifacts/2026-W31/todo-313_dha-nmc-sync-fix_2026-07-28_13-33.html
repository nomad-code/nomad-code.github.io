mirror sync restored

The hourly sync-upstream job on the nomad-code mirror of dhammaorg/portal-v2 had never once run green. Two independent faults stacked: the upstream credential was never minted, and a checkout default silently overrode it once it was.

Bug 1 · secret

Token never minted

UPSTREAM_TOKEN was an unchecked box since setup. The org blocks fine-grained PATs, so a fresh classic PAT — repo scope only, 90-day expiry — went in via a clipboard-to-sealed-box script; the token never touched the transcript.

Bug 2 · workflow

Checkout override

actions/checkout persists its own auth header into git config by default. That header outranks the token in the fetch URL, so upstream fetches hit a 404 wall as GITHUB_TOKEN. A clean-runner probe proved the token itself was fine.

Fix

Explicit token URLs

Both workflows now check out with persist-credentials: false, and every remote operation names its token in the URL — upstream via the PAT, the mirror push via GITHUB_TOKEN.
