It never jiggled.

The slackgreen alias promised a mouse-jiggle keep-alive. The AppleScript inside has been a syntax error since the day it was pasted — error -2740 every ten minutes, while the echo line cheerfully reported success. Only caffeinate was ever real.

Rebuilt as a zsh function with a real input event

slackgreen() now sends an F15 key press — a key no Mac keyboard has — every 5 minutes via System Events. Genuine synthetic HID event, working 10-hour cap (override: slackgreen <hours>), and caffeinate dies with the shell. Verified end-to-end including Ctrl-C teardown through a real pty.

Three bugs in one line

Bug 1 · the jiggleInvalid AppleScript

System Events has no mouse location property. “set the mouse location to (get the mouse location)” cannot parse — that's the -2740 on every cycle.

→
Bug 2 · the lieFake success line

The echo runs unconditionally after osascript fails, so “Slack Keep-Alive Active” printed for months over a dead jiggler.

→
Bug 3 · the cap-t 36000 ignored

caffeinate discards -t when wrapping a utility. The “10hr cap” was fiction; the loop ran until Ctrl-C.

Bonus: even if the AppleScript had parsed, setting the mouse to its current position generates no input event. Slack reads OS idle time from the last HID event — the design could never have worked. Net effect of the old alias: the Mac stayed awake, but presence still went away.

slackgreen()

slackgreen() {
    local hours="${1:-10}"
    local end=$(( $(date +%s) + hours * 3600 ))
    caffeinate -di -w $$ &  # dies with shell
    local caf=$!
    trap "kill $caf 2>/dev/null; return" INT TERM
    echo "slackgreen: active for ${hours}h"
    while (( $(date +%s) < end )); do
        osascript -e 'tell application
          "System Events" to key code 113'
        echo "Slack Keep-Alive Active: $(date)"
        sleep 300
    done
    kill $caf 2>/dev/null
}

Loose end: the old broken instance was still running during the audit (caffeinate -id -t 36000 bash -c 'while true…', PID 40327). Kill it and start fresh: kill 40327 && source ~/.zshrc && slackgreen.
