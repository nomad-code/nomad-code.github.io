Four distinct operators

Safety and hygiene

1

Branch early. Carry only the context the tangent actually needs.

2

Promote outcomes, not transcripts. Preserve the seed and result; let scaffolding decay.

3

Archive before delete. Deleting a parent can remove spawned descendants.

4

Keep Git truthful. Linear owns workflow; the artifact is a readable projection.
