Get all your shots back. In one file.

The Spica 3 is a photometric monitor: it measures each shot, then broadcasts the numbers to whatever software was running. It keeps no permanent database of its own — so your ~3,339 swings aren't in the device, they're trapped in the caches and exports of GSPro, the GolfJoy apps, E6, and Creative Golf, in five different formats. This is the plumbing that gets them out and merges them into one clean CSV you own — parsed locally in your browser, nothing uploaded. It's the data companion to the strokes-gained loop in TODO-83: the loop only compounds if the data lands somewhere durable.

the mission · one CSV you own00 / the goal

You don't recover shots from the launch monitor — you recover them from the software that was listening when you hit them. Photometric units compute ball & club numbers on impact and stream them out; the record lives wherever that stream landed. So "get all 3,339 shots" is really five smaller jobs: find each store, export it to a flat file, and merge the flat files. The tool in §02 does the merge for real; §01 is the map.

before you start · one correction The research brief pulls in squaregolf-connector and a "SquareGolf bridge." Those are for the Square Golf launch monitor — a different device. Your Spica 3 is a GolfJoy unit that talks to GSPro, E6 Connect, Creative Golf, and GolfJoy's own apps. Skip the SquareGolf path entirely unless you also own that hardware. And treat every exact Windows path / database table name in the brief as "probably right, verify locally" — some are AI-generated. The merge tool below doesn't trust those schemas; it reads whatever columns your actual exports contain.

under the hood · why the CSV is honest03 / how it normalizes

Three rules make the merge trustworthy. First, never invent data: a missing metric is blank, never 0. Second, never overwrite meaning: device-measured carry and sim-physics carry get their own columns. Third, never silently delete a shot: cross-source duplicates are tagged and counted, only collapsed when you say so.

# horizontal launch → one signed float
L1.4 → −1.4   R2.5 → +2.5   2.5 Right → +2.5
−1.4 → −1.4 (already signed, passthrough)
# convention (RH golfer): + = right / up / open
# smash — computed only if absent
smash = ball_speed_mph / club_speed_mph

# cross-source dedup signature (raw measures only)
sig = round(ball_speed) | vla±.5 | hla±.5 | backspin±100 | club

The dedup key uses only physically invariant measures — never sim-derived distance — because the same shot broadcasts to GSPro and GolfJoy at once with different carries. Two similar wedge shots can look identical, so the default is tag, don't delete; tick "merge mirrored sessions" only when you truly logged one session to two apps. machine-side helpers · the two steps a browser can't do

SQLite caches and raw API payloads need a shell, not a browser. These two stdlib-only scripts turn them into CSV/JSON the tool above ingests. No pip install, nothing to trust but Python.

spica_sqlite_dump.py — GolfJoy / sim SQLite cache → CSV

#!/usr/bin/env python3
# spica_sqlite_dump.py — export a GolfJoy/sim SQLite cache to CSV (stdlib only)
# usage: python3 spica_sqlite_dump.py cache.db [table|"SELECT ..."] > spica_shots.csv
import sys, sqlite3, csv
db = sys.argv[1]; arg = sys.argv[2] if len(sys.argv) > 2 else None
con = sqlite3.connect(db); con.row_factory = sqlite3.Row; cur = con.cursor()
if not arg:                                   # auto-find the shot table — the brief's
    best, best_n = None, -1                    # 'tbl_shot_history' name is unverified
    for (t,) in cur.execute("SELECT name FROM sqlite_master WHERE type='table'"):
        try: n = cur.execute(f'SELECT COUNT(*) FROM "{t}"').fetchone()[0]
        except sqlite3.Error: n = 0
        print(f"  {t}: {n} rows", file=sys.stderr)
        if ("shot" in t.lower() or "swing" in t.lower()) and n > best_n: best, best_n = t, n
    if not best: sys.exit("no shot-like table found; re-run with an explicit table/SQL")
    query = f'SELECT * FROM "{best}"'
else:
    query = arg if arg.strip().lower().startswith("select") else f'SELECT * FROM "{arg}"'
rows = cur.execute(query).fetchall()
if not rows: sys.exit("query returned 0 rows")
w = csv.writer(sys.stdout); w.writerow(rows[0].keys())
for r in rows: w.writerow([r[k] for k in r.keys()])

spica_json_to_csv.py — GolfJoy Space API payload → CSV (or drop the .json straight into §02)

#!/usr/bin/env python3
# spica_json_to_csv.py — flatten a GolfJoy Space API payload to CSV (stdlib only)
# usage: python3 spica_json_to_csv.py payload.json > spica_shots.csv
import sys, json, csv
data = json.load(open(sys.argv[1], encoding="utf-8"))
def walk(node, ctx=None):
    ctx = ctx or {}
    if isinstance(node, dict):
        scalars = {f"session_{k}": v for k, v in node.items() if not isinstance(v, (list, dict))}
        merged = {**ctx, **scalars}
        for k, v in node.items():
            if isinstance(v, list) and k.lower() in ("shots", "data", "records", "results"):
                for it in v:
                    if isinstance(it, dict): yield merged, it
            else:
                yield from walk(v, merged)
    elif isinstance(node, list):
        for it in node: yield from walk(it, ctx)
rows = []
for sctx, shot in walk(data):
    flat = dict(sctx)
    for k, v in shot.items(): flat[k] = json.dumps(v) if isinstance(v, (list, dict)) else v
    rows.append(flat)
if not rows: sys.exit("no shots[]/data[] arrays found — inspect the JSON shape")
cols = list(dict.fromkeys(k for r in rows for k in r))
w = csv.DictWriter(sys.stdout, fieldnames=cols); w.writeheader(); w.writerows(rows)
