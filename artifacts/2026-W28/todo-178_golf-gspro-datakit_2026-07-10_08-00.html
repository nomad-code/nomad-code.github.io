05 · decisions & lessons

pinned One grid for everything. EPSG:26918 (UTM 18N, meters) + NAVD88 m, a 4,096 m square with its SW corner snapped to integer meters, held in site.json — DEM, RAWs, ortho and SVG all share it exactly, so every later stage overlays pixel-perfectly. Source LAZ arrived as NAD83(2011) Conus Albers in meters; units were detected from tile metadata, never assumed.
lesson Query lidar with the square’s hull, not the course bbox. The course-bbox query returned 9 tiles and left the square’s margins tileless; the hull query returned 31. site.json.bbox_lidar_query_wgs84 is the durable fix.
deferred VBMP imagery pending. Virginia’s VGIN ortho server refused connections all session (canonical host confirmed via OSM editor-layer-index). NAIP carries S1; the 6″ leaf-off re-fetch is a one-command upgrade later.
