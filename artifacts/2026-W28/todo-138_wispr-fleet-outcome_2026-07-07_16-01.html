01why the fleet stops being scary

Browser, not App Store

Claude Code on the web is a website. You log into claude.ai — one Claude account — in Safari / Chrome on any device. Different Apple IDs, a Pixel on Android, the virgin iPhone with nothing installed: none of it matters. No per-ID purchase, no license to move, no ecosystem lock-in to fight.

Cloud sessions, not device state

The session lives in the cloud (this one does). So you start on the M3 and keep prompting the same work from the iPhone on a walk, then glance at the output later. Nothing to sync, nothing to hand off. The device is just a window onto work that lives somewhere else.

Native voice per OS

Every device already ships a voice keyboard — iOS dictation, Gboard voice on the Pixel, Watch dictation. That's your engine everywhere you're not at a Mac. The local superwhisper rig from TODO-132 is the premium tier for the desk; it isn't required to prompt from a phone.

03the pedal + a travel trigger — parked, not blocking

The pedal is a trigger upgrade, not the skill (TODO-132 §0 / §5 already said this). It makes push-to-talk unconscious — it does not unlock anything you can't do today with a keyboard key or the on-screen mic. So it staying in J&T transit changes nothing about today's move.

When you want a mobile trigger to think about — the "travel pedal" question — the shape to evaluate later is a tiny Bluetooth device that sends one keystroke: a pocket BT keyboard with a rebindable key, or even a BT camera-shutter remote (they emit volume-up, which iOS can map). Either becomes a poor-man's PTT for the iPhone/iPad without the MIDI router. Parked as a later evaluation — not a purchase, not a blocker. The skill never waits for hardware.
