The nightly chain — and the gap

sn_pull→ tag ingest→ video mirror→ sgt_discover→ registry re-pull→ strokes gained→ per-shot join→ unsynced check→ reports→ artifact→ deploy + ping

Root cause: the scheduled path never had credentials

The creds are in ~/.config/zsh/secrets.zsh (SGT_EMAIL/SGT_PASSWORD/SN_EMAIL/SN_PASSWORD) — but launchd runs with a bare environment and never sources that file. So every night sgt_discover.py found no creds, exited 3, and skipped discovery silently. Interactive runs worked (your shell has the env); the 22:07 job was effectively blind. There is no secrets.sh — secrets.zsh is the file, and it's the single source of truth.

The fix — a wrapper that sources the secrets

#!/bin/zsh                       # refresh_cron.sh
source ~/.config/zsh/secrets.zsh              # the missing link
exec /usr/bin/python3 .../refresh.py --quiet "$@"

The launchd plist ProgramArguments now points at /bin/zsh refresh_cron.sh instead of python directly. No credentials.json, no plaintext in the plist — creds stay in secrets.zsh only.

The parser fix — the real gap

parse_scorecard matched a scorecard row only when it was followed by 18–25 numbers and then indexed values by hole − 1 — both assumptions bake in an 18-hole card. A back-nine league round is 9 holes with just IN/TOT subtotals (11 numbers), so the row never matched: the grid parsed empty, reconcile saw no gross, and flagged all nine holes not_played → strokes_gained had zero holes to score → +0.0.

# before: 18-hole only          # after: read the HOLE header row
re.search(rf"\b{label}\b"          mh = re.search(r"\bHOLE\b((?:\s+"
  r"((?:\s+(?:-|\d+)){18,25})")       r"(?:\d+|OUT|IN|TOT))+)", seg)
gross[hole - 1]                    # cols -> {hole_number: value}, drop OUT/IN/TOT
                                   gross.get(hole)   # keyed by real hole #

Now 9-hole (front or back nine) and 18-hole cards parse the same. Regression: the full 18-hole rounds (61665 R1/R2 = 68/79, hole 6 skip preserved) are byte-for-byte unchanged; the re-pull of all 14 registry rounds is clean.
