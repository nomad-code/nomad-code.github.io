Linked worktrees are execution state, so the checker reports them separately instead of pretending each is an independent clone. Parity means the same intended repository paths and recoverable commits—not byte-identical .git directories, dependencies, caches, or running sessions.

03

Four state lanes, four recovery owners

G

Source + config blueprint

~/dev. Git owns recovery. Dirty work becomes a reviewed commit, handoff ref, or bundle; live .git directories never ride bulk sync.

D

Durable non-Git data

~/ark, Documents, and media libraries. Time Machine, cloud, or a verified replica owns recovery. A restore test—not a path name—is the proof.

K

Credentials

1Password, Keychain, and machine-local secret files. Re-authenticate on each node. Credential exports never enter Git or peer mirroring.

R

Runtime state + cache

~/Library, Codex/Claude databases, XDG state, build output, and caches. Rebuild, re-download, or explicitly accept loss; never live-sync identity databases.

04

Should ~ move into ~/dev?

No—not all of it.

~/dev should contain declarative source and config blueprints. macOS and many apps hard-code mutable databases, credentials, device identity, caches, and open-session state under ~ and ~/Library. Relocating those bytes can break apps and merely moves the failure domain. The durable move is to make runtime state disposable and put irreplaceable data behind a tested backup or replica.

06

Path to green

Preserve code intentionally

Finish, commit, or hand off every dirty tree and stash. Put every local-only commit on an appropriate remote ref; never sweep personal and company work into one archive.

Choose the durable-data rail

M5 has capacity to be the second replica for M3’s durable files, but two machines are not an off-machine backup against theft, corruption, or simultaneous loss.

Handle the credential export separately

Confirm its contents are safely owned, then remove the plaintext export. Do not mirror it to M5 or mention its filename in artifacts.

Converge source, not app databases

Recreate canonical repos at reviewed commits. Keep linked worktrees, Codex sessions, Claude history, caches, and device identity machine-local.

Wipe one node at a time

Re-run the gate, erase one Mac, rebuild from the remote and backup rails, verify restore, then—and only then—consider the other.
